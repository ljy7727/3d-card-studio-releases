# 卡片工坊 Android 安装包

此仓库仅提供卡片工坊 Android 正式安装包、SHA-256 校验和及版本说明。

请从 [Releases](https://github.com/ljy7727/3d-card-studio-releases/releases/latest) 下载唯一 APK。应用内可在「设置 → 软件更新」检查和下载安装新版，安装需在安卓系统界面确认。

应用源码保存在独立私有仓库，此仓库不包含应用源码。Release 页面自动生成的 Source code 附件只包含本仓库说明文件。

Android 客户端需连接电脑端卡片工坊服务。首次正式版采用固定发布证书，可能无法覆盖此前的调试包或其他证书的测试包；升级前请记录设置并确认数据已保留。后续正式版持续使用相同证书。
