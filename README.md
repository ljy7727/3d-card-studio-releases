# 卡片工坊 Android 安装包

此仓库只提供正式 APK、SHA-256 校验和及版本说明，应用源码保存在独立私有仓库。

从 [Releases](https://github.com/ljy7727/3d-card-studio-releases/releases/latest) 下载 APK，或在应用「设置 → 软件更新」检查更新。安装需在安卓系统界面确认。

1.2.0 起支持手机独立、免费、离线完成图片导入、模型抠图、静态卡片合成、本机收藏与 PNG 导出，无需电脑、账号或付费接口。模型随安装包附带。电脑端仍可选，用于原有 Blender 渲染等功能。

本地合成导出 768×1076 PNG，透明主体最长边不超过 2048 像素；不是电脑三维渲染或动画的复刻。复杂背景和细小边缘的抠图质量因图片而异。

图片在本机处理，不上传服务器。卸载前请先导出重要作品。1.1.x 正式版本沿用相同证书覆盖升级；更早调试包或其他签名测试包可能无法覆盖，请先保留数据，勿直接卸载。
